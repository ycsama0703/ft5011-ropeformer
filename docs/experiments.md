# 实验方案

本文件是计划，不是已取得的结果。现阶段只完成模型与本地功能验证。

## 问题与假设

1. head vs standard：学习每头整体尺度是否有用？
2. grouped(G=2) vs head：放宽组间频率比例是否有额外收益？
3. grouped vs shared_group：收益是否需要 head 独立的分组参数？
4. 可选 G=1/2/4：更高自由度是否值得？G=1 应恢复原方法。

频率比例固定是原参数化的数学限制，但不代表整个 Transformer 无法建模
不同时间尺度。表达范围扩大也不保证泛化提升。按这些问题解释结果。

## 核心对照

| 名称 | 配置 | 角色 |
| --- | --- | --- |
| A | standard | 固定 RoPE |
| B | head | 原始每头单尺度 |
| C | shared_group, G=2 | 同层各头共享分组尺度 |
| D | grouped, G=2 | 主方法 |
| E（可选） | grouped, G=4 | 组数消融 |

所有对照默认使用 horizon_tokens 预测头（见 docs/plan_horizon_tokens.md）。pooled 头
仅用于"预测头消融"：同一 RoPE 模式在两种头下的差别，用于判断 RoPE 是否只有在参与
外推时才重要。rope_mode="none"（NoPE）只作诊断。

fixed_head 是可用的额外控制，必须明确写出非平凡初值。A-D 默认相同零 log-scale
初始化，避免初值本身混淆结论。保持其他参数初值尽量配对，使用相同随机种子。

真实任务再加入线性预测器与 LSTM；这两个 baseline 尚未实现。

## 数据

### 合成机制实验

先用一个或两个正弦成分加噪声，改变周期组合、幅度、相位和信噪比。
训练/验证/测试用独立生成的序列。比较单周期、双周期；对新周期组合的
泛化应单独报告。不要只让测试集复制训练轨迹。

examples/train_synthetic.py 只是固定 12/32 步周期、随机相位/幅度的双周期
管线示例，不能替代上述完整的机制实验。

examples/synthetic_multiscale.py 提供四种任务：fixed、random_period、quasi_periodic、
regime_switch。在旧的 pooled 骨架上已观察到（仅机制检查，非证据）：fixed 被线性模型
解到噪声水平；quasi_periodic 上线性与 Transformer 持平；各模式差距小于种子波动；
所有 log-scale 仅移动到 0.7–1.2 倍。这是改用 horizon_tokens 头的直接原因。

### 真实预测实验（待实现）

建议从 ETTh1 和 Weather 等两个适中规模公开数据集开始。数据集与目标由
小组最终确认，不绑定旧金融任务。明确下载来源、版本、时间范围、变量数、
缺失处理、切分位置与可用窗口数量。

先固定一个回看长度及两个预测长度，避免庞大网格。采用所选基准的标准
时间切分；窗口不得让训练标签进入验证期或测试期。验证/测试历史可以使用
预测起点之前已知的观测。

只在训练集拟合标准化，再应用于验证和测试。报告指标所在的尺度，所有模型
必须一致；需要原始单位时用训练集统计量反归一化。

## 训练协议

- 同一个输入投影、Transformer、池化与预测头，只改变 RoPE 配置。
- 小骨架起点：d_model=64, n_heads=4, num_layers=2, d_ff=128。
- MSE loss；验证集选最佳状态/早停。报告测试 MSE 和 MAE。
- 3 个配对随机种子起步，资源允许时增加到 5 个；报告均值和标准差。
- 相同训练步数上限、batch size、优化器、学习率候选与早停耐心。
- 给所有版本同样的 RoPE base 调参预算，随后冻结设置。合成实验默认网格 {1000, 10000}。
- 学习率 linear warmup + cosine decay，所有模式相同。
- 记录 log-scale 轨迹，先确认尺度是否真正移动，再解释模式差异。
- log_scales 默认无 weight decay；若使用单独学习率，应记录并公平调参。
- CPU/GPU、软件版本、耗时与训练参数量一起记录。
- 不默认加强迫尺度分离的损失；如后续添加，独立做消融。
- 测试集不用于选组数、频率范围、学习率或训练轮数。

## 分析

1. 学习曲线与训练/验证差距。
2. 每层每头分组尺度随训练的轨迹。
3. 有效频率布局及组间比例改变。
4. 按时间距离汇总的注意力，配合不同滞后区间遮挡实验。
5. 参数量、训练/推理耗时；更多组是否值得。
6. 预测长度外推：用 H_train 训练，测试 H > H_train（仅 horizon_tokens 头可做），
   报告逐步误差曲线。
7. 注意力贡献诊断：将注意力替换为零/单位矩阵、逐频带置零，判断改进是否来自 RoPE。

period=2*pi/frequency 只描述位置旋转。attention 图和参数差异不能独立证明
真实周期恢复、重要性或因果关系。

## 结果解释

- D 稳定优于 B：支持分组自由度在所测任务有用。
- C 接近 D：没有足够证据支持每头独立参数的必要性。
- B/D 相近且优于 A：整体缩放可能已足够。
- E 变差：更多自由度可能增加优化或泛化难度。
- 只有合成有效：机制存在，但真实任务收益有限。
- 全部接近：任务可能不敏感；先核查训练和公平性，不挑最好种子。
